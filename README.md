# Obrador · Gestión (preview)

Preview navegable del sistema de gestión para Obrador: pedidos, presupuestos, stock, costos y contable.

- Todos los datos son **ficticios** (recetas, costos, proveedores, gastos). Los precios de los packs salen de obrador.ar.
- Los cambios se guardan solo en el navegador de quien lo usa (localStorage). El botón "Restablecer demo" vuelve al estado inicial.
- Formulario de pedido para clientes: `#/pedir`.
- Sitio estático (HTML + JS sin build). La infraestructura real está pendiente de definir.
